## 3. 缺口清单（最实质）

重组后的 FR 结构把「可验收的功能点」吸收得较全，但**设备屏幕三主页的页面内容契约**与**诵经基调类 qualitative 内容**被 FR 化压缩后存在缺口，按实质排序如下：

- **G1 — 经文页整页内容契约缺位。** 简报「设备屏幕」节与附录 §5.3 定义经文页＝大号当前字＋少量前后文＋本轮进度，且 MVP 不显示选经入口。PRD FR-E-006 只列「AMOLED 提供木鱼页、经文页、统计页和下滑设置页」，通篇未定义经文页上到底呈现什么；FR-E-007 仅以「经文页触摸不计数」提及。经文页是设备常驻三主页之一，属 PRD 声称的「唯一产品行为权威」应承载的可观察行为。落点建议：FR-E-006 补经文页内容契约。
- **G2 — 木鱼页信息元素不完整：「本轮进度＋今日计数」未落 FR。** 简报定义木鱼页＝可点击电子木鱼＋7 字滚动带＋**本轮进度**＋**今日计数**＋丝滑动画；经文页与完成流程也反复引用「本轮进度」。PRD FR-E-006/007 只写了 7 字带、点击区与顶部状态栏，木鱼页自身的「本轮进度／今日计数」显示项无任何 FR 落点（统计页的今日/累计与之是不同位置）。这是贯穿诵经上下文的核心信息元素，建议在 FR-E-006 补齐。
- **G3 — 7 字带「只呈现已诵内容、空位低对比度占位、不预览未来经文」的诵经基调丢失。** 简报附录 §5.2 明确：经文带只展示最近已诵出内容；新一轮开始时未填充位用低对比度占位、**不预览未来文字**。PRD FR-E-006 只保留「最近已诵字左移、新字右入」，丢掉了「不预览未来经文 + 低对比度占位」这一反剧透/诵经连续感的定性约定——正是 qualitative 内容在 FR 结构化中最易丢失的一类。建议补入 FR-E-006 或 UJ 体验描述。
- **G4 — 「一天续航」成功指标未进 PRD §10。** 简报「成功标准」明确「每天约 30 分钟实际敲击及余下待机的使用模型下，设备至少支持完整一天，最终以样机功耗实测为准」；PRD §10 SM-1…SM-6 无任何续航/全天指标，仅 §11 工程验证入口 5 把「一天续航」当作测量项。对「自己愿意反复使用」的个人原型，全天续航是核心可感知成功标准，建议在 §10 增设对应 SM（可带「以样机实测为准」口径）。

## 4. 次要不一致 / 低优先级

- 导航交互顺序细节未进 PRD：附录 §5.1「下滑进入设置页、返回后保持原主页」「PWR 亮屏时按木鱼→经文→统计顺序循环」、§5.4「立即同步反馈进行中/成功/待同步/失败」在 PRD（按 PRD addendum §1，产品行为只维护在 `prd.md`）与 PRD addendum 均无落点。PWR 长按关机在 PRD 中仅以「长按不由固件模拟关机」间接表达，未写「由板级电源电路负责开关机」。属顺序/状态粒度问题，可随 G1/G2 的 FR-E-006/007 修订一并补，不单独重开。
- 术语「正式输入」vs「有效敲击」：简报附录 §4.1 用「正式输入源」、主文用「有效敲击队列」；PRD 术语表已把「有效敲击」定义为「嵌入式层确认并写入本地累计的一次正式输入」，二者已调和，不构成缺口。
- 设备端统计页与小程序记录页的今日归属、离线差量按 backend 确认日期归档（FR-B-008）与简报「backend 为日统计权威」口径一致，无冲突。

## 5. 判定

**结论：基本 reconciled（reconciled with reservations）。** 09-08 简报的定位、硬件方向、输入模型、联网/同步、完成流程、小程序契约与全部 decision/override/assumption 均已落入重组后的 PRD 正文（FR-E-/FR-B-/FR-F-）与 PRD addendum，编号保留且归属正确。缺口集中在**设备三主页的页面内容契约（G1/G2）与诵经基调类体验约定（G3）**，以及**一天续航这一成功指标未进 §10（G4）**——均为 PRD 正文 FR-E-006/§10 层面的补丁级修订，不推翻两层结构，无需重新打开决策。建议在后续 bmad-prd Update 中以一处小 diff 闭合 G1–G4，并同步本文件状态。
