## 3. 专项检查：AD-16 SQLite → JSON 零库覆盖

**判定：有意覆盖且 spine 内部自洽，无残留 SQLite/数据库表述。**

- 文件头部「本轮覆盖决策」块明确声明：后端持久化改为 JSON 文件、零数据库，覆盖 PRD FR-B-009 与旧根文档「单文件 SQLite」决定，详情见 AD-16。
- AD-16 Rule 通篇「不引入任何数据库」；描述为 JSON 原子落盘（临时文件 + fsync + rename），落在 `cloud/backend/data/`；`[ASSUMPTION A-2]` 把 JSON 文件布局细节放进 Deferred。
- §Structural Seed 目录树、系统容器图、Design Paradigm 图、Consistency Conventions（「JSON 文件写入原子化」）与 Stack 表均使用「JSON 文件」表述，无 SQLite/数据库残留。
- Capability Map 仍按组绑定 FR-B-001~009 至 AD-2/3/5/6/16，FR-B-009 由 AD-16 显式覆盖，不构成遗漏。
- 全文唯一出现「SQLite」之处即头部 override 说明，属历史决策引用，意图明确。
- 补充：PRD 文档树（architecture.md、docs/…）仍列旧文档与 SQLite 语义，属历史遗留，不计缺陷；未来由 PRD 更新流程对齐（附录 §1 已声明）。

## 4. 已核对且「确有治理 / 显式 Deferred」的约束（不属遗漏）

- 完成遮罩期间输入忽略：AD-1 + 工程验证门禁「完成遮罩期间输入忽略」。
- 音频失败不阻塞计数/持久化/同步：AD-12（FR-E-005/006/009）。
- 高速连击合并音效、动画不丢字：AD-12。
- 未校时「待校时」、设备不存绝对敲击时间：AD-6。
- 离线积压上限 1000、达上限拒绝并提示：AD-3（FR-E-004/FR-B-002）。
- 充电暂停输入/经文/音频：AD-13。
- 单身份单设备：AD-16；微信细节 Deferred A-5。
- 心经末字完成语义 / 从头开始 / 退出 / 完成锁定：AD-2（backend 拥有完成锁定）+ AD-17（frontend 仅在收到 backend 完成确认后展示，FR-F-005）+ 工程验证门禁「完成礼花与从头开始/退出语义正确」。设备本地「末字即完成」由 AD-9/AD-15 的本地立即呈现与 round_state 持久化承接，判定已落位。
- 7 字带不丢字/动态加速、小程序不跳字重字乱序：AD-12 / AD-17。
- 三主页 + 下滑设置 + 顶部状态栏、不沿用四主页数量：§Structural Seed 复用清单与「不沿用…四主页数量」。
- PWR 长按不由固件关机：AD-13；板级 GPIO 表含 PWR 只读。
- 同步状态词表（本地已记录/同步中/已同步/待同步/同步失败；待设备应用）：Consistency Conventions。
- WebSocket vs 轮询、JSON 布局、版本档位、域名备案、OTA/BLE/GPS 业务、多设备/迁移/账号：Deferred。
