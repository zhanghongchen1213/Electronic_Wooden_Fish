## Story

As a 小程序用户，
I want 在 cloud 确认完成后查看全文并选择下一步，
so that 新旧篇章都能保留。

**覆盖需求：** FR-C-016、UX-DR18、AD-19

本 Story 是 Epic 6 的**完成态闭环**：在 6.3 LIVE + 6.4 REPLAY/OFFLINE 之上，交付  
`[READING][DONE]`、`[OVERLAY][DONE]`（短促礼花 + 「从头开始/退出」独立弹窗）、篇章归档折叠，以及经 `action_id` 调用已有 backend `POST /api/v1/sync/round-action` 的幂等跨轮动作。

**不**实现记录页统计（6.6）、设备/设置业务（6.7–6.8）、14 态像素终验（6.9）、真机联调（Epic 7）。  
**必须复用** 6.4 `readingStream` / `isReplaying` / 水位持久化、6.3 投影与进度分母、5.6 `api/request`、5.2/5.5 已交付的完成权威与 `completion` 帧——禁止第二 HTTP 栈、禁止本地假完成、禁止改 backend/契约字节、禁止手改 `heart-sutra.generated.ts`。

## Acceptance Criteria

1. **仅 backend 完成确认后进入完成态（FR-C-016 / UX-DR18 / AD-17）**
   **Given** backend 权威为 `round_state=completed` 且 `pending_completion=false`（快照水合或 WS `completion` 帧）
   **When** 阅读页处于可展示完成的相位（非 `offline`；若在 `replay` 则须展示追上完成游标后再弹）
   **Then** 保留全文、进度显示 100%（分母仍为 `COUNTS.consumableHan=260`），短促礼花 + 独立完成弹窗（`modal-done`）出现一次
   **And** `pending_completion=true` 或权威仍为 `in_progress` 时**禁止**声称完成、禁止弹窗、禁止礼花
   **And** 弹窗打开期间不追加新正式字符（冻结展示推进；新 delta 不得写入当前正文前缀）

2. **从头开始 / 退出经 `action_id` 幂等（FR-C-016 / AD-19 / 5.2 端点）**
   **Given** 用户点击「从头开始」或「退出」
   **When** 经统一 `api/request` 调用 `POST /api/v1/sync/round-action`，body 仅 `{ action: "restart"|"exit", action_id }`
   **Then** 「从头开始」成功后：关闭弹窗；在阅读区下方建立新 `round_id` 区块（游标回 0 / 空或首字等待）；旧篇章全文可折叠归档；累计高水位不由前端清零
   **And** 「退出」成功后：关闭弹窗；保留完成态全文与 100% 进度及历史统计语义（统计页数字仍属 6.6，本 Story 只保证不破坏完成态可读）
   **And** 同一按钮连点 / 同 `action_id` 重试不得创建多个轮次；进行中请求须防双发

3. **文案与视觉闭包（UX-DR18 / UX-DR23 / MINI-06）**
   **Given** `cloud/miniapp-design/ewf-miniapp-ui-export.html` 与 `UI_CONTRACT-miniapp.md`
   **When** 渲染 DONE banner / OVERLAY
   **Then** 弹窗标题「本轮完成」、摘要形态对齐「心经进度 260 / 260 字 · 100%」（数字由 `progressView`/`COUNTS` 派生，禁止硬编码假分母 303）、动作「从头开始」「退出」
   **And** DONE 态 banner 标题「本轮完成」、说明「心经进度 {n} / {total} 字」；礼花短促、琥珀强调、非常驻；减少动效时取消粒子插值但保留一次状态确认（弹窗仍出现）
   **And** 可见文案禁止 TODO/draft/placeholder/Node ID/`data-pencil-id`/调试说明；生产属性不得残留设计节点标识

4. **门禁与范围边界**
   **Given** 6.4 REPLAY/OFFLINE 已交付
   **When** 完成本 Story
   **Then** frontend 单测通过（含 6.3/6.4 回归 + 完成弹窗/冻结/幂等/归档护栏）；`git diff --check` 干净
   **And** 不得改 `docs/contracts/**`、Embedded、backend 业务逻辑；不得引入 Alova/第二请求库；不得发明新 sync 路径名以外的 wire 字段

### 必须作出的裁决（推荐项；实现须写入注释）

**裁决 A：完成相位模型**
- **推荐：`uiPhase='done'` + `overlayVisible: boolean`。** 进入条件：权威 `round_state==='completed' && !pending_completion`，且 `!isReplaying`，且 `displayedCursor >= roundCursor`（全文已展示）。
- 快照冷启动已是 completed：水合后直接 DONE + 弹窗（礼花仍短促一次）。
- `pending_completion===true`：保持 `live`/`replay` 语义，进度可到 100% 数字边缘但**文案/弹窗不得「本轮完成」**（避免抢跑）。

**裁决 B：弹窗期入站帧**
- **推荐：overlay 打开时，`delta` 不推进 `displayedCursor`/`正文`；若 `round_id` 变化则关窗并走快照 resync（防设备侧已 restart）。** `completion` 重复帧只做 seq 水位，不重复播礼花（用 `celebrationPlayedForRoundId` 门闩）。

**裁决 C：`action_id` 生命周期**
- **推荐：每次用户点击生成新键并写入 `inflightActionId`；请求期间按钮 disabled；失败保留键允许重试同一键；成功清空。** 禁止无防抖连点导致两键双 restart。

**裁决 D：restart 后 UI**
- **推荐：将当前全文推入 `archives[]`（`{ roundId, chars, collapsed: true }`），再 `applySnapshot(restartResponse)` 清空当前正文为新轮；默认折叠旧篇。** 归档仅内存 + 可选 storage，非 AD-2 权威。

**裁决 E：exit 后 UI**
- **推荐：关 overlay，保持 `uiPhase='done'` 与全文/100%；不强制跳转记录页。** 底部导航仍可达（6.1）。

**裁决 F：礼花与减少动效**
- **推荐：CSS/少量 view 粒子，时长约 600–1000ms，结束卸载；读 `uni.getSystemInfo`/`prefers-reduced-motion` 类信号若可得则跳过粒子。** 不得常驻动画循环。

**裁决 G：与 6.4/6.6 边界**
- **推荐：不改 REPLAY 排队核心；DONE banner 优先于 LIVE「已同步」。** 记录页数字仍 6.6；本 Story 测试可用 mock 快照断言「exit 不清 round_id/completed」。
