## Story

As a 设备使用者，
I want 设备界面在固定画布上保持稳定的页面骨架和中文字形，
so that 每个状态都能被可靠阅读。

**覆盖需求：** FR-E-006、UX-DR1、UX-DR2、UX-DR4、UX-DR5、UX-DR14、AD-10

本 Story 是 Epic 3 的**壳层与字体基线**：把仍残留的 legbot 外骨骼/BLE/支付 UI 替换为 DEVICE-01 三主页常驻 pager + 按需设置页骨架，重建 SquareLine/字体合同与校验工具，并建立独占 `ui_task` 接线。  
**不**实现木鱼七字带与三环（3.2）、经文 13 槽流（3.3）、统计卡投影（3.4）、设置同步五态视觉闭包（3.5）、完成遮罩与跨轮（3.6）。  
**必须复用** Epic 2 已交付的 `device_nav_service` 页意图/`settings_open`/`screen_state`、`state_service` 快照、`co5300_bsp`/`cst9217_bsp`，以及 Story 4.1 canonical《心经》生成头——禁止第二套导航真源或第二套经文誊写。

## Acceptance Criteria

### AC 1：DEVICE-01 画布与三主页骨架（UX-DR1 / UX-DR2 / FR-E-006）

**Given** DEVICE-01 Pen 与 `UI_CONTRACT-device.md` 已冻结  
**When** 建立 LVGL 8.4 / SquareLine 1.6.1 工程并导出到固件  
**Then** 画布固定 **410×502**、圆角 **110**、屏幕边距 **16px**、关键净空 **≥8px**、状态栏高 **24px**；三主页由 `screen_shell` 常驻横向 pager 承载（内容宽 1230，`MUYU/JINGWEN/TONGJI` 根帧分别位于 0/410/820）；设置页 `SHEZHI` 为按需加载的独立 410×502 Screen  
**And** 视觉真源只认 `Embedded/lvgl-design/ewf-device-ui.pen`（作者导出 HTML：`ewf-device-ui-export.html` / 约定名 `ewf-device-ui.html`）；**禁止**继续以 legbot `watch-lvgl` 外骨骼页、BLE 候选、支付页、助力档位作为产品页面；full frame 不添加外层展示板/装饰背景

### AC 2：generated / bindings / `ui_task` 边界（UX-DR14 / AD-10）

**Given** SquareLine 导出与 bindings 接线  
**When** 任意显示刷新、导航投影或状态栏补丁发生  
**Then** `Embedded/components/ui/generated/` **只**含布局、字体、事件空桩；业务路由、状态投影、运行时颜色/图标补丁全部位于 `bindings/`；**所有** LVGL API 仅由单一 `ui_task` 调用  
**And** 其他任务（nav/progress/sync/feedback/power）只发布 typed 意图或只读快照，不得直改对象树、不得绕过 BSP 操作 QSPI/I²C 显示链路

### AC 3：状态栏壳与信号单槽（UX-DR5）

**Given** 三主页常驻壳已加载  
**When** 投影状态栏骨架  
**Then** 顶部 statusbar 常驻呈现 4G/Wi-Fi/蓝牙/GPS 四个 **单槽** signal-status（connected/no-signal/disabled 由运行时补丁切换，不复制隐藏节点）、电池百分比/符号槽、同步短语槽；图标可见 **不等于** MVP 启用 BLE/Wi-Fi/GPS 业务链路  
**And** 本 Story 可用本地注入/占位事实驱动槽位切换可测；完整低电/故障/同步词表闭包与产品文案精修属后续 3.x，但骨架不得再渲染外骨骼助力/步数/档位文案

### AC 4：字体合同与五路缺字闭合（UX-DR4）

**Given** 设备字体构建执行  
**When** 生成 Noto Serif SC / Noto Sans SC 子集并同步到 `generated/fonts`  
**Then** 字形只覆盖：canonical《心经》可消费汉字（`docs/contracts/canonical/`，`scripture_version=HS-1.0.0`，260 可消费字）+ 必要 UI 字符（状态/统计/设置短文案、数字、标点 `，` 等）；木鱼/经文用 Serif，状态/统计/设置用 Sans；**SquareLine 字体资产与 `Embedded/components/ui/generated/fonts` 字节一致**  
**And** 缺字检查覆盖五路：SquareLine 静态标签、导出 C 标签、状态投影标签、运行时动态标签、代码字体切换（`font_codes`）；**禁止**手工编辑 `.c` 位图；`missing_glyphs: 0` 且 `squareline_firmware_font_sources_identical: true` 前不得宣称字体完成

### AC 5：门禁与范围边界

**Given** Epic 2 导航/设置事实与 Story 4.1 canonical 已可用  
**When** 完成本 Story  
**Then** 主机可测项（骨架页 ID、pager 几何常量、generated 无业务符号扫描、字体合同校验脚本）通过；环境允许时 ESP-IDF v5.5.4 / esp32s3 增量构建通过并记入 `docs/embedded/build_records/`  
**And** 用户可见文案只允许产品文案/状态文案/canonical《心经》；禁止 `TODO`/`draft`/`placeholder`/Node ID/`data-pencil-id`/AI 思维链进入最终页面；不得改 `docs/contracts/**` 经文正文语义；不得引入充电暂停输入 gate（PRD final）；不得启用 BLE/Wi-Fi/GPS 业务
