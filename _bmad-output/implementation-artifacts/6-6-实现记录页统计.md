## Story

As a 小程序用户，
I want 查看今日、周期、累计和连续诵读统计，
so that 我能回看长期使用情况。

**覆盖需求：** FR-C-017、UX-DR19、UX-DR22、AD-6

本 Story 是 Epic 6 的**记录页统计呈现**：在 6.1 记录壳 + 6.2 鉴权门闸之上，消费已交付的 backend `GET /api/v1/sync/stats`（Story 5.3），交付  
`[RECORDS][BASE]` 五指标（今日 / 近 7 日 / 近 30 日 / 累计 / 连续）与 `[RECORDS][EMPTY]`，以及 loading / fail / refreshed 可操作状态。

**不**实现设备页（6.7）、设置镜像（6.8）、14 态像素终验与印谱装饰终验（6.9）、真机联调（Epic 7）。  
**必须复用** 5.6 `api/request`、6.2 `ensureAuthenticated`、6.1 `PageShell`/令牌/`pages/records` 壳——禁止第二 HTTP 栈、禁止本地假统计、禁止改 backend/契约字节、禁止把 `readingStream` 展示计数或本地待同步差量写入任何正式数字。

## Acceptance Criteria

1. **只呈现 backend 已确认统计（FR-C-017 / UX-DR19 / AD-2 / AD-6）**
   **Given** `GET /api/v1/sync/stats` 返回已确认统计或空历史（`HistoryStatsResponse`）
   **When** 打开记录页或下拉刷新成功
   **Then** 展示五指标，字段与 wire 一一对应：
   - `today_taps` → 「今日敲击」+ 单位「次」
   - `last_7_days_taps` → 「近 7 日」
   - `last_30_days_taps` → 「近 30 日」
   - `total_taps` → 「累计敲击」+「次」
   - `streak_days` → 「连续诵读」+「天」
   **And** 正式数字**只**来自该响应；禁止用 `readingStream`/`acked_total` 本地镜像、本地敲击缓存或「待同步差」加算任何指标
   **And** `empty===true` 时进入 EMPTY，不把「全 0」伪装成有历史；`pending_sync===true` 时数字仍只用已确认字段，可用非数字状态提示（不得抬高数字）

2. **loading / empty / fail / refreshed 可操作（FR-C-018 子集 / EXPERIENCE）**
   **Given** 统计请求处于加载、无历史、失败或刷新完成
   **When** 用户进入页面、下拉刷新或点击重试
   **Then** 分别呈现 loading / empty / fail / refreshed（或等价短促「已刷新」反馈）；失败保留可执行重试；下拉刷新单飞，不并发制造重复请求
   **And** 空态文案对齐冻结 HTML：「暂无记录」+「暂无已确认数据」（替换壳层旧句「尚无确认记录」）
   **And** 失败文案对齐状态板：「同步失败」+「重试同步」（或同语义短句）；不得出现实现说明/调试标签

3. **无盒化账本视觉与令牌（UX-DR22 / UI_CONTRACT / MINI-06 HTML）**
   **Given** `ewf-miniapp-ui-export.html` RECORDS.BASE 与 `UI_CONTRACT-miniapp.md` 无盒化原则
   **When** 渲染统计列表
   **Then** 使用冻结令牌（纸面 `#f4f0e5`、card `#fffdf6`、ink/muted、低对比刻线 `#9e7b5722`）；今日可为语义必要大数卡，其余为账本行/双列；低对比 1px 分隔；**不用**装饰渐变/多层盒堆叠伪造数据层级
   **And** 页眉可显示「已确认数据」状态胶囊（对拍 HTML）；触区与底导航仍 ≥44×44（沿用 6.1 tabBar）
   **And** 可见文案禁止 TODO/draft/placeholder/Node ID/`data-pencil-id`/调试说明；生产属性不得残留设计节点标识

4. **门禁与范围边界**
   **Given** 5.3 `/stats` 与 6.1–6.5 frontend 基线已交付
   **When** 完成本 Story
   **Then** frontend 单测通过（含统计映射/空态/失败重试/禁止本地加算护栏 + 既有回归）；`git diff --check` 干净
   **And** 不得改 `docs/contracts/**`、Embedded、backend 业务逻辑；不得引入 Alova/第二请求库；不得发明 wire 字段名以外的统计键；不得在本 Story 做 6.9 像素终验

### 必须作出的裁决（推荐项；实现须写入注释）

**裁决 A：数据入口**
- **推荐：仅 `GET /sync/stats`。** 不用 snapshot 拼统计；不用 WS 推统计（5.3/5.5 未定义 stats 帧）。进入页与下拉刷新重新拉取。

**裁决 B：空态判定**
- **推荐：完全信任响应 `empty`。** 前端不自行 `total===0 && today===0` 重判（避免与 catch-up 滞后语义打架）。

**裁决 C：`pending_sync` 呈现**
- **推荐：数字仍只绑五字段；`pending_sync===true` 时页眉由「已确认数据」改为弱提示「含待同步」或次要一行说明——不得把差值加进今日/累计。** 若文案空间不足，至少不抬数字；具体短句写入 `RECORDS_COPY` 并避免发明营销句。

**裁决 D：失败时是否保留上次成功数据**
- **推荐：保留上次 `ready` 数字并叠加 fail banner/重试（避免闪空白）；首次进入失败则纯 fail+重试。**

**裁决 E：刷新单飞**
- **推荐：`inflight` Promise 共享；下拉与重试共用；完成调用 `uni.stopPullDownRefresh`。** refreshed 可用短 toast「已刷新」或页眉闪态，≤1s。

**裁决 F：数字格式**
- **推荐：整数原样；千分位可选对齐 HTML（`3,210`）用轻量格式化，勿引入 i18n 库。** 单位：「次」用于今日/累计；连续用「天」；近 7/30 HTML 未强制单位后缀——可只显示数字。

**裁决 G：与 6.7/6.9 边界**
- **推荐：不做设备电量/同步动作；印谱印章可极简占位或省略，像素与装饰终验交给 6.9。** 本 Story 护栏以数据正确与状态可操作优先。
