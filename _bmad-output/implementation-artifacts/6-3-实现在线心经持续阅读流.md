## Story

As a 小程序用户，
I want 只看到 backend 已确认并按顺序追加的经文，
so that 手机阅读与设备诵读保持一致。

**覆盖需求：** FR-C-013、FR-C-014、UX-DR15、AD-17、AD-19、NFR2

本 Story 是 Epic 6 的**在线阅读流（LIVE）**：在 6.1 纸面壳 + 6.2 登录直达之后，把阅读页从空态「等待设备诵读」升级为 **17 槽 append-only《心经》纸面 + 唯一总进度 + 在线逐字动画调度**。数据只来自 backend 已确认快照/差量；字形由 `round_cursor` + canonical `STEPS` 派生。  
**不**实现断线 REPLAY/OFFLINE banner 与 `replay_cursor` 权威恢复（6.4）、完成礼花/弹窗（6.5）、记录/设备/设置业务（6.6–6.8）、14 状态像素终验（6.9）。  
**必须复用** 5.6 `api/request`、5.5 已交付的 `GET /sync/snapshot` + `ws` 帧语义、6.1 令牌/壳层、6.2 鉴权门闸与 `userAuth`——禁止第二 HTTP 栈、禁止发明 `glyph` wire 字段、禁止可点击木鱼。

## Acceptance Criteria

1. **17 槽 append-only 阅读流（FR-C-013 / UX-DR15 / AD-19）**
   **Given** 阅读页已登录，且收到权威快照或在线 `delta` 使 `round_cursor` 前进
   **When** 渲染正文
   **Then** 按 canonical `STEPS[0 .. round_cursor-1]` 的 `display` 字符**按序 append**到固定 **17 槽/行**（标点计槽；`slotWidth=20`）；每个确认步进只消费一次；**已有前缀不覆盖、不清空、不重排**
   **And** 未确认槽位不得预览未来经文（空槽留白/低对比基线即可，**禁止**灰字剧透整篇）
   **And** 最新已确认字：正文槽 **18px** Noto Serif SC；最新字 **28px** + `{colors.mini.focus}`（`#a66b3a`）+ 持续 **2px** 下划线贴在该字下方；旧字弱化为 ink / muted
   **And** 只保留**一组** `scripture-progress`：文案形态对齐 HTML（如 `42 / 260 字` + 百分比如 `16.2%`）；分母 = `COUNTS.consumableHan`（260）；分子 = 当前轮已确认可消费字数 `round_cursor`；percent = clamp(`round_cursor / 260 * 100`, 0–100）；轨道填充 focus 色
   **And** 页面**没有**可点击电子木鱼、没有第二进度条、没有本地假敲击入口

2. **在线逐字动画调度（FR-C-014 / NFR2 / AD-17）**
   **Given** 单次 `delta` 或快照相对展示水位前进 Δ≥1（`round_cursor` 或等价已确认游标）
   **When** 动画调度执行
   **Then** 将 Δ 个步进**逐个入队**展示；队列积压时可缩短步进间隔追平，**不得跳过、合并、乱序或重复**同一步进
   **And** 队列清空后恢复基线间隔；已上屏前缀在加速期间持续可见
   **And** 「当前字」**不是** WS/REST wire 字段：只用 `round_cursor` + `STEPS` 派生（承接 5.5 裁决）

3. **在线数据入口与非权威边界（AD-17 / AD-2 / FR-C-006 消费面）**
   **Given** 用户进入阅读 tab（已通过 6.2 `ensureAuthenticated`）
   **When** 建立 LIVE 会话
   **Then** 先 `GET /api/v1/sync/snapshot`（统一 `api/request` + Bearer）用水位/`round_id`/`round_cursor` 水合金字塔正文；再按契约派生 `ws(s)://{origin}{REST}/ws?token=` 建立**单一** SocketTask；消费 `type=delta` 推进展示队列
   **And** Pinia/本地仅缓存展示队列、`last_applied_seq`、UI 相位等**非权威**状态；正式进度/统计不得用本地计数冒充
   **And** `completion` / 完成弹窗 / REPLAY·OFFLINE banner / `replay_cursor` 落盘策略属 6.4/6.5——本 Story 可忽略 `completion` 帧或只更新水位**不**弹窗；断线时允许静默重查快照+重连，**不得**假称已交付 6.4 回放 UI

4. **门禁与范围边界**
   **Given** 6.1/6.2 壳与登录、5.6 单飞、canonical 生成物已就位
   **When** 完成本 Story
   **Then** frontend 单测通过（含既有单飞/登录/壳层回归 + 本 Story 阅读流护栏）；`git diff --check` 干净
   **And** 可见文案禁止 TODO/draft/placeholder/Node ID/`data-pencil-id`/调试说明；空态金值用产品句「等待设备诵读」/「尚未有已确认经文」
   **And** 不得改 `docs/contracts/**`、Embedded、backend 业务逻辑；不得引入 Alova/第二请求库；不得手改 `heart-sutra.generated.ts`

### 必须作出的裁决（推荐项；实现须写入注释）

**裁决 A：游标 → 字形映射**
- **推荐：`round_cursor = N` 表示已确认前 N 个可消费步进；展示字符串 = `STEPS.slice(0,N).map(s => s.display).join('')` 再按码点/字面逐槽切分（UTF-16 下标按汉字/标点各 1 槽）。**
- `N=0` → 空态；`N=COUNTS.consumableHan` → 全文 display 槽填满（完成 UI 仍归 6.5）。

**裁决 B：动画基线与加速**
- **推荐：基线间隔 280–360ms（默认 320ms）；积压时线性降至下限 48–80ms；禁止 interval=0 的同步 for 循环「瞬间填满」。**
- 队列深度用 `targetCursor - displayedCursor`；清空后回到基线。

**裁决 C：快照首屏是否走动画**
- **推荐：冷启动/重进阅读页时，若快照 `round_cursor` 已 >0，允许一次性水合到目标（无逐字动画）以避免每次进页长回放；随后 LIVE delta 一律走队列。**
- 理由：完整「离线回放」体验属 6.4；本 Story 保证在线增量不跳字。

**裁决 D：WS 派生与鉴权**
- **推荐：从 `API_BASE_URL` 解析 origin + path，后缀 `/ws`，query `token=accessToken`；使用 SocketTask（传入 `complete`）；全局单一实例。**
- 心跳：收 `heartbeat` 回 `heartbeat_ack`（字段按契约）；不要发明 REST 式 ping。

**裁决 E：进度文案格式**
- **推荐：计数行 `${cursor} / ${COUNTS.consumableHan} 字`；百分比一行保留 1 位小数（对齐 HTML `16.2%`），clamp 0–100。**
- 只渲染一组进度组件。

**裁决 F：与 6.4/6.5 的交接**
- **推荐：本 Story 暴露稳定 store API（`applySnapshot`/`applyDelta`/`displayedCursor`）；6.4 在其上加 REPLAY 相位与 banner；6.5 监听 `round_state===completed`/`completion` 帧弹窗。**
- 6.3 不得把完成弹窗做「顺便做了」。

**裁决 G：并发与旧轮次**
- **推荐：`delta.round_id !== currentRoundId` → 不把旧轮字符 append 进当前流；触发快照重拉后按新 `round_id` 重建。**
- 与契约 §8「旧轮次事件不得写入当前正文」一致。

- **心跳方向：** backend 发 `heartbeat`，frontend 回 `heartbeat_ack`（与常见「客户端 ping」博客模板相反——以契约为准）。
- **字体：** 小程序可用网络/本地 Noto Serif SC；若包体受限，本 Story 可用系统衬线回退，但字号/颜色/下划线几何必须对齐；字体子集终验不阻塞本 Story 逻辑门禁。
