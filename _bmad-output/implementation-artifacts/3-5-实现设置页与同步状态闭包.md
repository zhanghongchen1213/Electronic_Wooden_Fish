## Story

As a 设备使用者，
I want 在设置页修改音量、亮度、熄屏和立即同步并看见结果，
so that 我能控制设备而不误解命令是否生效。

**覆盖需求：** FR-E-007、FR-E-009、UX-DR11、UX-DR13、UX-DR26、AD-5

本 Story 是 Epic 3 的**设置页与同步状态投影**：在 Story 3.1 按需 `SHEZHI` 骨架 + Story 2.4 设置持久化/立即同步事实 + Story 2.5 活动窗口客户端之上，把当前仅有四行标签占位的 `ui_scr_shezhi` 升级为 DEVICE-01 正式设置屏——**首屏四行控件 + sync-btn 五态 + 第二页设备身份**——并保证 action 文案与累计同步状态词表一致。  
**不**实现完成遮罩与跨轮（3.6）、小程序设置镜像/待设备应用（6.8）、Air780 真机对拍（Epic 7）。  
**必须复用** `device_settings_*`（volume/brightness/timeout/applied_revision）、`device_nav_service_request_sync`/`complete_sync`、`watch_nav_update_t.sync_status`、状态栏同步短语（`待同步/同步中/已同步/同步失败`）、`ui_service`/`bindings` 模式——禁止第二套设置 NVS、在 UI 自写设置、复制整屏做同步态、在 `generated/` 写业务。

## Acceptance Criteria

### AC 1：设置页两页结构与控件闭包（FR-E-007 / UX-DR11）

**Given** 用户下滑进入设置页（`settings_open==true`，按需 `SHEZHI` Screen）  
**When** 查看或修改控件  
**Then**  
1. **首屏最多 4 行**（378×80、间隔 8，viewport 378×344）：  
   - **屏幕亮度**：分段胶囊 `低/中/高`（默认中；wire `low|mid|high`，**禁止**写入 `medium`）  
   - **自动熄屏**：分段胶囊 `5秒/15秒/30秒`（默认 15）  
   - **音量**：0–100 滑块 + 右侧数值（默认 50；0=静音）  
   - **立即同步**：`sync-btn` 行（左侧标题「立即同步」+ 右侧 action 胶囊）  
2. **第二页**（content 高 520，page-2 @ top=344）：**木鱼版本**、**木鱼ID**（`device-identity` 同构行）  
**And** 结构复用同一骨架；默认值为中亮度、15 秒、音量 50；修改经 `device_nav`/`device_settings` 统一 API 落盘并跨重启保留；**不得**再开第二套 settings NVS

### AC 2：sync-btn 五态只覆写 action（FR-E-009 / UX-DR13）

**Given** 用户点击立即同步或同步请求处于不同阶段  
**When** `sync-btn` 状态改变  
**Then** 仅切换 action 文案与状态色，**不复制整屏**、不重建亮度/熄屏/音量骨架；组件态对齐 `BASE/BUSY/OK/PENDING/FAIL`（Pen `fWCbZ` / `cQ5wd`）  
**And** action 文案与累计同步状态词表一致：  

| nav/sync 事实 | sync-btn 组件态 | action 文案（与状态栏词表对齐） |
| --- | --- | --- |
| `IDLE`（尚无飞行请求） | `BASE` | 「立即同步」（可点） |
| `BUSY` | `BUSY` | 「同步中」 |
| `OK` | `OK` | 「已同步」 |
| `PENDING` | `PENDING` | 「待同步」 |
| `FAIL` | `FAIL` | 「同步失败」 |

**And** 禁止发明「成功/失败了」等偏离词表文案；禁止把 backlog 累计态与立即同步飞行态混成第二套短语

### AC 3：供电条件与充电边界（UX-DR26 / PRD final）

**Given** 设备处于 USB 外供、电池供电或外供并充电任一种供电条件  
**When** 打开设置并改亮度/熄屏/音量或点立即同步  
**Then** 三种供电条件均保持设置与同步功能可用（不因充电切断控件）  
**And** 旧 UX 变体 `MUYU.CHARGING_PAUSE` **不得**实现为输入/音频/同步暂停 gate；本 Story 不接线该整屏变体为闸门

### AC 4：输入与导航边界（FR-E-007）

**Given** 用户在设置页  
**When** 触摸控件、滑动列表或返回  
**Then** 设置页普通触摸**不**产生 `device_touch`/正式计数；实体 `physical_pvdf` 仍可推进统一队列；熄屏首触只唤醒  
**And** 上滑/返回关闭设置保持原主页；PWR 短按先关设置（2.4 已裁决）；本 Story **不**重写导航状态机，只补控件 intent → `device_nav`/`settings` API

### AC 5：边界与卫生门禁

**Given** Story 3.1–3.4 壳层/木鱼/经文/统计与字体合同已绿，Story 2.4/2.5 设置与同步事实可用  
**When** 完成本 Story  
**Then** 主机可测：默认值、三档亮度/熄屏切换、音量 0/50/100、sync 五态文案映射、不复制整屏、禁 `medium` wire、禁 `CHARGING_PAUSE` gate；字体合同覆盖设置动态标签与 `font_codes`；`missing_glyphs: 0`；用户可见文案无 TODO/draft/placeholder/Node ID/`data-pencil-id`  
**And** 不依赖 cloud；不实现小程序设置镜像；不改 `docs/contracts/canonical/**`；所有 `lv_*` 仅 `ui_task`；不实现完成遮罩（3.6）
