## Story

As a 设备诵读者，
I want 完成《心经》后能明确选择重新开始或退出，
so that 当前篇章和历史积累都不会被误操作覆盖。

**覆盖需求：** FR-E-006、FR-E-007、UX-DR12、AD-19（兼 FR-E-003 完成遮罩忽略输入、FR-C-004 设备侧对偶、AD-7 自动模式完成停表）

本 Story 是 Epic 3 的**收口**：在 Story 2.1/2.2 输入闸门与 `pending_completion`、Story 2.6 完成停表、Story 3.1–3.5 四页骨架之上，把木鱼页升级为可进入 `MUYU.DONE_OVERLAY`——**复用现有状态栏/进度/字带骨架 + `modal-done` 浮层**——并提供本地「从头开始 / 退出」跨轮动作（篇章动作族 `action_id` 幂等）。  
**不**实现 cloud `POST /sync/round-action` 真机联调（5.2 已在 backend 完成；设备侧仅本地语义 + 现有 HTTPS report 可携带 `action_id`/`round_*`）、小程序礼花弹窗（6.5）、`CHARGING_PAUSE` 输入暂停 gate、第二套 OVERLAY 顶层 Screen。  
**必须复用** `progress_service`/`progress_transaction` 单事务组、`state_service` tap gate、`power_auto_mode` 完成停表、`ui_muyu_*` 投影路径、`ui_service`/`bindings` 模式——禁止 UI 自写 NVS、禁止第二套 round 计数、禁止在 `generated/` 写业务。

## Acceptance Criteria

### AC 1：完成遮罩投影（FR-E-006 / UX-DR12）

**Given** 本地轮次到达末字并进入完成锁定（`tap_pending_completion==true` 和/或 `tap_round_state==completed`，见裁决 A）  
**When** UI 投影完成状态（亮屏、主页可为 MUYU；遮罩语义以 gate 为准）  
**Then**  
1. 木鱼页显示完成遮罩：全屏 overlay `#00000099`（约 60% 黑）+ 卡片 `338×190 @ left=36,top=150`，底 `#121212`，圆角 16  
2. 卡片文案闭包：标题「本轮完成」；摘要「心经进度 {cursor} / 260 字」（完成时 260/260）；动作「从头开始」「退出」  
3. **冻结所有正式输入**：`physical_pvdf` / `device_touch` / `automatic_tap` 均不推进累计与游标；木鱼触区不触发三环正式 flash；遮罩期间点击按钮以外区域不得绕过 gate  
**And** 遮罩**不**创建第二套页面骨架 / 不另建顶层 `OVERLAY.DONE` Screen；复用 `modal-done` 与现有 statusbar / scripture-progress / charcell / woodfish 组件（下方骨架可保持末字态，遮罩盖上）

### AC 2：从头开始 / 退出与 action_id 幂等（FR-E-007 / FR-C-004 设备对偶 / AD-19）

**Given** 用户选择「从头开始」或「退出」  
**When** 动作通过篇章动作族 `action_id` 执行（本地 `progress_service` 公开 API）  
**Then**  
- **从头开始（restart）**：`round_id := 旧 round_id + 1`（溢出护栏见裁决 F）、`round_cursor=0`、`round_state=in_progress`、`pending_completion=false`；**不**清零 `local_total`/`acked_total`；遮罩隐藏；字带回到空带/首字可再推进；经文页流语义保持「新轮从首字再积」（不要求本 Story 清空历史显示缓冲的像素级策略以外的 cloud 归档）  
- **退出（exit）**：保留完成态（`round_state=completed`、当前 `round_id`/`round_cursor`）、`pending_completion=false`；**累计与旧篇章统计保留**；遮罩可隐藏，但 **completed gate 仍为真**（输入继续冻结，直至日后 restart）  
- **同 `action_id` 重放**：事务组与 gate 与首次成功一致，不二次 `round_id+1`、不二次翻转  
- **新 `action_id`**：才允许再次 restart（exit 同键幂等）  
**And** 未处于完成锁定时 restart → 拒绝（保持原事务 + 中文日志）；exit 在非完成态上为拒绝或幂等 no-op（实现须在 policy/javadoc **钉死一种**，推荐与 5.2 对齐：非完成态 exit → 拒绝）

### AC 3：自动模式完成停表与再启用（FR-E-011 / AD-7）

**Given** 自动模式运行中到达完成锁定，或用户在遮罩上操作  
**When** 完成 gate 生效或 restart/exit 完成  
**Then** 自动模式在完成时**停止**（2.6/`power_auto_mode` 已有 `completed` 停表——本 Story 不得回退）  
**And** restart 后自动模式**保持关闭**；新轮次必须再次显式 BOOT0 短按启用；禁止 restart 隐式重开自动敲击

### AC 4：导航与其它页边界（FR-E-007）

**Given** 完成锁定期间  
**When** 用户左右滑 / PWR 短按 / 下滑设置  
**Then** 导航仍可用（可看经文/统计/设置）；设置页触摸仍不计数；他页普通触摸不计数  
**And** 实体 PVDF 在完成锁定期间仍被 gate 忽略（与木鱼页一致）；本 Story **不**重写 2.4 导航状态机  
**And** 若设置页在遮罩期间打开：不因设置控件解除完成锁定

### AC 5：边界与卫生门禁

**Given** Story 3.1–3.5 与 progress/tap/power 门禁已绿  
**When** 完成本 Story  
**Then** 主机可测：末字→遮罩可见；遮罩期三类输入不推进；restart 新 round_id+游标 0+累计不变；exit 保留 completed+累计；同 action_id 幂等；restart 后 auto 仍关；字体合同覆盖「本轮完成」「从头开始」「退出」及摘要动态字；`missing_glyphs: 0`；用户可见文案无 TODO/draft/placeholder/Node ID/`data-pencil-id`  
**And** 不依赖 cloud；不改 `docs/contracts/canonical/**`；不改契约正文（只读引用）；所有 `lv_*` 仅 `ui_task`；不实现 `CHARGING_PAUSE` gate；不实现小程序礼花
