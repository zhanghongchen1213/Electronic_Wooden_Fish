## Story

As a 设备诵读者，
I want 木鱼页在每次敲击时显示下一个字并给出短促光效，
so that 物理动作和视觉节奏保持一致。

**覆盖需求：** FR-E-006、UX-DR6、UX-DR7、UX-DR8、AD-19、NFR2

本 Story 是 Epic 3 的**木鱼页核心节奏**：在 Story 3.1 已交付的 `screen_shell` / `ui_task` / 字体合同基线上，把 MUYU 从标题+静态木鱼色块升级为可投影的 7 槽字带 + 心经进度 + `tap-rings` flash，并把木鱼热区接到已有 `tap_input_service_submit_device_touch`。  
**不**实现经文页 13 槽 append-only（3.3）、统计页今日/累计卡（3.4）、设置 sync-btn 五态（3.5）、完成遮罩与跨轮动作（3.6）。  
**必须复用** `progress_service` 的 `round_cursor`/`local_total`/`pending_completion` 快照、`ewf_scripture_canonical.h` 步偏移、`device_nav_service` 的 `active_page`/`screen_state`、`tap_input_service` 统一队列、3.1 的 `ui_service`/`bindings`——禁止第二套经文誊写、第二套计数路径或在 `generated/` 写业务。

## Acceptance Criteria

### AC 1：七字带右入左移与唯一 `glyph-current`（UX-DR8 / AD-19 / NFR2）

**Given** 木鱼页处于可输入状态（亮屏、非完成锁定、非故障 gate）  
**When** 收到 `physical_pvdf`、`device_touch` 或本地已确认进度快照推进（含 `automatic_tap` 经统一队列落盘后的游标变化）  
**Then** 按 canonical **步**展开显示流：`step[i] = 可消费汉字 + 紧随非消费字符`；显示流按字符槽填入固定 **7** 槽，新内容从**右侧**进入、旧字左移；任意时刻至多一个可见 `glyph-current`（大字 + `{colors.brand.amber.400}`）；空位仅为低对比占位，**绝不**预览未来经文  
**And** 标点随相邻汉字同一步出现且**不消耗敲击**；标点在字带中**占槽**（与 `docs/contracts/canonical/README.md`「标点计槽」一致）；分母固定 `EWF_SCRIPTURE_CONSUMABLE_COUNT=260`，不得把 7 当成经文上限

### AC 2：心经进度投影（FR-E-006）

**Given** `watch_state` 快照含 `tap_round_cursor`（已诵可消费字数）  
**When** bindings 投影 MUYU  
**Then** `scripture-progress` 显示 `已诵 / 260`（或契约文案等价的「心经进度 N / 260」）与 **0–100** 百分比；`round_cursor==260` 时保持 `260/260` 与 100%（完成遮罩交互属 3.6，本 Story 只投影数值）  
**And** 本地尚未被 cloud 确认的差值不得伪装成「已同步正式进度」；同步短语继续走状态栏槽（3.1），本 Story 不伪造 `sync-ok`

### AC 3：三环 `idle→flash→idle` 160ms（UX-DR7 / UX-DR26）

**Given** 有效事件触发木鱼页正式反馈，且来源为 `physical_pvdf` 或 `device_touch`  
**When** bindings 更新 `tap-rings`  
**Then** 恰好三道椭圆描边在 **160ms** 内完成 `idle→flash→idle`；flash 描边色为运行时琥珀色补丁 `{colors.brand.amber.300}=#e6bd69`；母版/generated **只**导出 idle 描边（白半透明系，DESIGN：`#fbfaf066/#fbfaf044/#fbfaf033`），**禁止**建立金色环节点变体或复制整屏  
**And** 连续事件**只重启**光效、不叠加节点、不建立独立等待队列；`automatic_tap` 推进字带与进度但不触发三环（DESIGN `tapSources: [physical_pvdf, device_touch]`）；完成锁定、故障 gate、熄屏首触**不**触发正式光效

### AC 4：木鱼唯一计数触区（UX-DR6）

**Given** 亮屏且 `active_page==MUYU`、未完成锁定、未故障锁定、非熄屏首触唤醒路径  
**When** 用户点击电子木鱼热区（≥96×96，含 `woodfish-anatomy`/`cmp_woodfish_mark` 可见主体）  
**Then** 经 bindings/`ui_task` 转发为 `tap_input_service_submit_device_touch`，进入与 PVDF 同一有效队列；经文/统计/设置页普通触摸与非木鱼区域触摸不计数  
**And** `woodfish-anatomy` 只负责器物识别，不另建第二计数入口；熄屏首触只唤醒（既有 nav），不产生 `device_touch`

### AC 5：边界与卫生门禁

**Given** Story 3.1 壳层与字体合同已绿  
**When** 完成本 Story  
**Then** 主机可测：7 槽窗口算法（空/中/满/标点占槽/不预览未来）、flash 重启合并、触区 gate、进度百分比；字体合同覆盖动态字带标签与 `font_codes`；`missing_glyphs: 0`；用户可见文案无 TODO/draft/placeholder/Node ID/`data-pencil-id`  
**And** 不实现 CHARGING_PAUSE 输入暂停 gate（PRD final）；不改 `docs/contracts/canonical/**` 正文语义；所有 `lv_*` 仅 `ui_task`；不依赖 cloud
