# 电子木鱼硬件离线落图资料

本目录现在以离线人工复刻为主，不再把嘉立创 EDA 网页自动化当作交付门槛。

## 入口文件

- [完整原理图复刻 HTML](电子木鱼-完整原理图复刻.html)：单文件、无外部依赖；包含 P01–P07 标准符号 SVG 原理图（电阻、电容、电感、二极管、运放/比较器、连接器与 IC 功能引脚）、逐页网络/针脚明细、GPIO、I²C、BOM、开放项和来源。
- [完整原理图 SVG 图集](电子木鱼-完整原理图图集.svg)：七页纵向矢量图，适合打印或在矢量工具中放大检查。
- `pages/`：P01–P07 单页 SVG；HTML 中每页右上角的“单页放大”可直接打开对应页面。
- `import/`：先前生成的嘉立创 EDA 标准版 JSON 草稿，仅作为网络参考；未宣称已导入或通过 ERC。

## 手工复刻顺序

1. 打开 HTML，按 P01 → P07 逐页复刻；先放真实库元件，再按页面上的全局网络名连接。
2. P01 先完成 `VBUS_5V`、`BAT_PROTECTED`、`VBAT_SW`、`3V3`、`AUDIO_5V` 和 USB MUX，确认 `BQ_SYS` 不去 M100。
3. P02 按 GPIO 合同放置 ESP32-S3-WROOM-1-N16R8；P03 严格按 24-pin FPC 表；P06 按 UART 交叉表。
4. 原理图 ERC 前逐项处理 HTML 中的“必须样机验证”标记；不要把推荐初值直接视为最终生产值。

## 当前验证状态

- `python3 tools/validate_hardware_manifest.py`：静态 GPIO、I²C 地址、电源边界、连接器和 FPC 清单通过。
- 嘉立创 EDA：工程中已保留 P01–P07 页树，但元件未自动放置；ERC、PCB DRC、封装/3D 和样机均未验证。
- 连接器、FPC 接触方向、M100 载板物理针脚、PVDF 阈值/滞回、4G 发射峰值和音频腔体仍按开放项处理。

HTML/SVG 由 `tools/generate_hardware_schematic_html.py` 从 `电子木鱼-硬件网络清单.json` 生成；修改网络合同后请重新运行生成器并再次运行静态校验。
