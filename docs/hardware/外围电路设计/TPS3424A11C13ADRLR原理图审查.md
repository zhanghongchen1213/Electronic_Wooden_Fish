## 1. 证据边界

网表可以确认端点和网络同名关系，但不能单独证明：

- U5 的 `{Value}` 没有导出为 `TPS3424A11C13ADRLR`，只能由 `SOT-583-8` 封装和 pin 号进行拓扑比对；
- U8 的 `{Value}` 没有导出为 `TPS22965DSGR`，pin 3 的 ON 功能需由同版 BOM/符号确认；
- SW1/SW2 的 `{Value}` 未导出，四脚轻触开关的内部 1-2、3-4 短接关系需按精确 MPN 和封装图确认；
- 测试点是否真正可探测、焊盘方向、PCB 走线、ERC/DRC、焊接和时序波形均未被网表证明。

## 5. 结论

### 已核对符合

- U5 pin 3 VDD 接 `VSYS`，pin 8 KILL 接 `VSYS/VDD`；
- U5 pin 4/5 分别接 120 pF/4.7 nF 对地电容；
- U5 pin 6 RESET 同网连接 TPS22965 候选 U8.3、ESP32 IO46 和 TP_PWR_STATE；
- U5 pin 7 INT 经 R7=10 kΩ 上拉到 V3V3，并引出 TP_PWR_INT；
- PWR 按键 PB→GND、BOOT 按键 BOOT0→GND 的拓扑符合预期；
- TP_BOOT0、TP_PWR_INT、TP_PWR_STATE、TP_RESET_N 的实际网络端点清晰。

### 需要修正或补证

1. 在 EDA/BOM 中保留 U5=`TPS3424A11C13ADRLR`、U8=`TPS22965DSGR` 的精确属性。
2. 物理网名继续使用 `PWR_STATE`；在文档中将 `SYS_EN` 写成该网的功能名，避免误解为第二条线。
3. 补交 SW1/SW2 的精确 MPN 或封装图，或完成 SW2.1–SW2.3 的断电通断测试。
4. 通过示波器验证短按约 50.6 ms、长按约 1.98 s、RESET/PWR_STATE 掉电和 ESP32 启动绑带时序。
5. 当前证据不足以宣称 ERC、PCB DRC、按键功能、下载模式或样机通过。
