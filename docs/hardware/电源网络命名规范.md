# 电子木鱼电源网络命名规范

> 状态：硬件文档统一口径（2026-09-17；按键控制器由 TPS3424 换为 LTC2954，`PWR_STATE` 由推挽改为开漏上拉）
>
> 本文件是 `docs/hardware/` 后续原理图、BOM、PCB、测试记录和固件接口文档的电源网络命名入口。网络名描述“板级实际网络”，器件数据手册中的 pin 名和连接器原厂符号保持原样，不把 pin 名当成新的板级别名。

## 1. 命名规则

- 板级电源网络使用全大写 ASCII；电压轨统一以 `V` 开头。
- 不在网络名中加入器件厂商名、封装名或重复的电压信息；电压和来源写在本表说明中。
- 同一条物理网络只允许一个正式网络名。器件 pin 与连接器 pin 可以保留原厂名称，但必须映射到正式网络名。
- `TP_` 只用于测试点名，后面直接接正式网络名；不再从旧网络名派生测试点。
- `GND` 是公共回流网络，不使用 `V` 前缀。

## 2. 正式板级电源网络

| 正式网络名 | 来源/边界 | 标称范围 | 用途与约束 |
| --- | --- | --- | --- |
| `VBUS` | USB-C 连接器的 VBUS，经保险丝/保护后进入 BQ25895 VBUS | 5 V | USB 受电端输入；不表示 USB 数据线，也不直接给 4G 模组供电 |
| `VBAT` | 受保护单节电池的 BATT+，连接 BQ25895 BAT | 3.0–4.2 V | 电池正端；“已保护”是边界属性，不再写进网络名 |
| `VSYS` | BQ25895 SYS，经 power-path 输出，连接 LTC2954 VIN 与 TPS22965 IN | 3.5–4.2 V | 充电器系统节点；为 PWR 控制器提供 USB-only/电池-only 常供电；不得绕过 TPS22965 直连 M100/Air780 VIN。范围依据：`SYS_MIN` 的**可配置**范围为 3.0–3.7 V（BQ25895 SLUSC88C p.35 REG03），但**本项目按 `REG03 = 0x3A` 配置为 3.5 V**，故实际下限取 3.5 V，不取可配置范围下限；p.19 §8.2.6.1 明写电池完全耗尽时系统仍被调节在最低系统电压之上，上界随 `VBAT` 满充 4.2 V。**该网最高 4.2 V，高于 ESP32-S3 IO 的 3.6 V 上限，任何 3.3 V 域器件都不得直挂此网。** |
| `VMAIN` | TPS22965 OUT | 与 `VSYS` 同域，范围相同 | 经硬件电源开关控制的高电流主电源；只供 4G 模组 VIN 和 TLV62569 `VIN`。不直供 NS4150B，也不供 ES8311（codec 绝对最大 3.6 V） |
| `V3V3` | TLV62569 OUT | 3.3 V | ESP32、显示逻辑、I²C、PVDF 比较器、ES8311 的 `AVDD`/`DVDD`/`PVDD` 和其他 3.3 V 逻辑负载 |
| `V3V3_A` | `V3V3` 经磁珠或负载开关后的输出 | 3.3 V | 只供 NS4150B `VCC`；禁止 ES8311 与功放共此网；禁止把 `V3V3_A` 从 `VMAIN` 直接分出 |
| `VLCD` | `V3V3` 经 0 Ω 默认装配电阻 | 待实物/时序验证 | 只表示面板 VBAT 功能，不等同于 `VBAT`；`VMAIN` 经 0 Ω 备选装配位直取（默认 DNP）。**默认装配电阻与 DNP 备选装配位硬性互斥，绝不可同时装配**——同时贴上会把 `V3V3` 抬到 `VMAIN`，超 ESP32-S3/ES8311 的 3.6 V 绝对最大。面板侧 OCP21351 的 VIN 推荐 2.9–4.6 V，故 `VLCD` 取 `V3V3` 侧为默认装配 |
| `GND` | USB-C、电池及整板公共回流 | 0 V | 所有器件回流；按功率、模拟和音频区域做布局分区，不创建同义地网名 |

## 3. 器件 pin 与板级网络映射

| 器件/接口原生标记 | 统一接入网络 | 说明 |
| --- | --- | --- |
| BQ25895 `VBUS` | `VBUS` | pin 名保留 `VBUS` |
| BQ25895 `BAT` | `VBAT` | pin 名 `BAT` 不作为板级网络名 |
| BQ25895 `SYS` | `VSYS` | 取消 `BQ_SYS` 这一含厂商前缀的别名 |
| TPS22965 `IN`/`VBIAS` | `VSYS` | 两个输入脚同网 |
| TPS22965 `OUT` | `VMAIN` | 取消 `SYS_MAIN` 这一复合别名 |
| TLV62569 `VIN` | `VMAIN` | `VIN` 仅表示器件 pin；网络名使用 `VMAIN` |
| Air780EGP/M100 `VIN` | `VMAIN` | 不创建 `M100_VIN`；连接器端仍可标注原厂 `VIN` |
| ES8311 `AVDD`/`DVDD`/`PVDD` | `V3V3` | 三路供电同接 `V3V3`；`PVDD` 必须与 ESP32 I²C/I²S 同域。禁止接到 `V3V3_A` 或 `VMAIN`。需要隔离时只允许从 `V3V3` 再串本地磁珠，不得占用板级 `V3V3_A` |
| NS4150B `VCC` | `V3V3_A` | 不把 `V3V3_A` 写成普通 `V3V3`；禁止直挂 `VMAIN` |
| PY206 FPC `VBAT`/pin 8 | `VLCD` | 面板候选轨与电池 `VBAT` 严格区分 |
| LTC2954 `EN` | `PWR_STATE` | 开漏高有效控制输出，经 **100 kΩ 上拉至 `VSYS`** 取得高电平；只驱动 TPS22965 的 `ON` 与 TLV62569 的 `EN`，**不接任何 ESP32 引脚**——其高电平 = `VSYS`（最高 4.2 V），超出 3.3 V 域 IO 的输入上限。**该上拉是必需项**：下游两脚均无内部上拉（TPS22965 仅 0.5 µA 漏电规格；TLV62569 明写 `EN` 不得悬空），本网恰好一组上拉，不得再并第二组 |
| LTC2954 `INT` | `PWR_INT` | 开漏低有效按键状态输出；PB 按下即拉低、并在**按住期间持续为低**（不是脉冲）；10 kΩ 上拉至 `V3V3`；接 ESP32-S3 的 IO8，固件以边沿中断读取并自行测低电平时长，不得按电平轮询 |
| LTC2954 `KILL` | `V3V3`（经 100 kΩ） | 不是独立板级网络。无主控应用时按手册端接到低电压输出电源，本设计经 100 kΩ 上拉至 `V3V3`；`KILL` 只做端接，**不得由任何 GPIO 驱动**，否则与「固件不接管硬件关机」冲突 |

音频分轨固定为：`VMAIN → TLV62569 → V3V3`（含 ES8311）→ 磁珠或负载开关 → `V3V3_A`（仅 NS4150B）。`VMAIN` 是这条链路的上游，不是功放或 codec 的器件供电网。

BQ25895 的 `PMID`、`REGN`、`SW`、`BTST` 是器件局部节点，不属于对外电源轨：文档中分别写作 `VPMID`、`VREGN`、`SW_BQ`、`BTST_BQ`，必要时在括号中附原始编号。`BAT_NTC`、`LCD_EN` 等是温度或控制信号，不归入电源轨表；`PWR_STATE` 与 `PWR_INT` 同属控制信号，命名见 §3。`SYS_EN` 是「`PWR_STATE` 驱动 TPS22965」这一功能的历史称呼，不是独立网络名，新文档不再使用。

## 4. 测试点和后续文档写法

测试点命名一律为 `TP_` 加**正式网络名**，不再从旧网络名派生。当前在用：

- 电源轨：`TP_VBUS`、`TP_VBAT`、`TP_VSYS`、`TP_VMAIN`、`TP_V3V3`、`TP_V3V3_A`、`TP_VLCD`
- 控制与信号：`TP_PWR_STATE`、`TP_PWR_INT`、`TP_BOOT0`、`TP_RESET_N`、`TP_I2C_SDA`、`TP_I2C_SCL`、`TP_LCD_TE`、`TP_PVDF_RAW`、`TP_PVDF_ADC`、`TP_PVDF_CMP`
- 按实物既有命名保留、未采用 `TP_` 前缀的两处：`CW2015_ALRT_TP`（电量计 `ALRT` 网络）、`GND`（地测试点）。两者与本节规则不符，后续新增测试点一律按本节规则命名；既有实物名在改板前保持不变。

后续文档按“网络名（用途/边界）”首次展开，例如“`VBUS`（USB-C 5 V 受电输入）”，不要再写 `VBUS_5V`、`BAT_PROTECTED`、`BQ_SYS`、`SYS_MAIN`、`3V3`、`3V3_AUDIO`、`LCD_VBAT`、`M100_VIN`、`TP_3V3` 或其变体作为新网络名。
