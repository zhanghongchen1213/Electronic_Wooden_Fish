# 电子木鱼电源网络命名规范

> 状态：硬件文档统一口径（2026-09-14）
>
> 本文件是 `docs/hardware/` 后续原理图、BOM、PCB、测试记录和固件接口文档的电源网络命名入口。网络名描述“板级实际网络”，器件数据手册中的 pin 名和连接器原厂符号保持原样，不把 pin 名当成新的板级别名。

## 1. 命名规则

- 板级电源网络使用全大写 ASCII；电压轨统一以 `V` 开头。
- 不在网络名中加入器件厂商名、封装名或重复的电压信息；电压和来源写在本表说明中。
- 同一条物理网络只允许一个正式网络名。器件 pin、连接器 pin 和网表端点可以保留原厂名称，但必须映射到正式网络名。
- `TP_` 只用于测试点名，后面直接接正式网络名；不再从旧网络名派生测试点。
- `GND` 是公共回流网络，不使用 `V` 前缀。

## 2. 正式板级电源网络

| 正式网络名 | 来源/边界 | 标称范围 | 用途与约束 |
| --- | --- | --- | --- |
| `VBUS` | USB-C J1 的 VBUS，经保险丝/保护后进入 BQ25895 VBUS | 5 V | USB 受电端输入；不表示 USB 数据线，也不直接给 4G 模组供电 |
| `VBAT` | 受保护单节电池 J2 BATT+，连接 BQ25895 BAT | 3.0–4.2 V | 电池正端；“已保护”是边界属性，不再写进网络名 |
| `VSYS` | BQ25895 SYS，经 power-path 输出，连接 TPS3424 VDD 与 TPS22965 IN | 随 NVDC 系统电压变化 | 充电器系统节点；为 PWR 控制器提供 USB-only/电池-only 常供电；不得绕过 TPS22965 直连 M100/Air780 VIN |
| `VMAIN` | TPS22965 OUT | 随 `VSYS` 变化 | 经硬件电源开关控制的高电流主电源；只供 4G 模组 VIN 和 TLV62569 `VIN`。不直供 NS4150B，也不供 ES8311（codec 绝对最大 3.6 V） |
| `V3V3` | TLV62569 OUT | 3.3 V | ESP32、显示逻辑、I²C、PVDF 比较器、ES8311 的 `AVDD`/`DVDD`/`PVDD` 和其他 3.3 V 逻辑负载 |
| `V3V3_A` | `V3V3` 经磁珠或负载开关后的输出 | 3.3 V | 只供 NS4150B `VCC`；禁止 ES8311 与功放共此网；禁止把 `V3V3_A` 从 `VMAIN` 直接分出 |
| `VLCD` | PY206 FPC pin 8 的面板模拟供电候选 | 待实物/时序验证 | 只表示面板 VBAT 功能，不等同于 `VBAT`；首版可由 `VMAIN` 或独立面板稳压器提供 |
| `GND` | USB-C、电池及整板公共回流 | 0 V | 所有器件回流；按功率、模拟和音频区域做布局分区，不创建同义地网名 |

## 3. 器件 pin 与板级网络映射

| 器件/接口原生标记 | 统一接入网络 | 说明 |
| --- | --- | --- |
| BQ25895 `VBUS` | `VBUS` | pin 名保留 `VBUS` |
| BQ25895 `BAT` | `VBAT` | pin 名 `BAT` 不作为板级网络名 |
| BQ25895 `SYS` | `VSYS` | 取消 `BQ_SYS` 这一含厂商前缀的别名 |
| TPS22965 `IN`/`VBIAS` | `VSYS` | 两个输入脚同网 |
| TPS22965 `OUT` | `VMAIN` | 取消 `SYS_MAIN` 这一复合别名 |
| TLV62569 `VIN` | `VMAIN` | `VIN` 仅表示器件 pin；网络名使用 `VMAIN` |
| Air780EGP/M100 `VIN` | `VMAIN` | 不创建 `M100_VIN`；连接器端仍可标注原厂 `VIN` |
| ES8311 `AVDD`/`DVDD`/`PVDD` | `V3V3` | 三路供电同接 `V3V3`；`PVDD` 必须与 ESP32 I²C/I²S 同域。禁止接到 `V3V3_A` 或 `VMAIN`。需要隔离时只允许从 `V3V3` 再串本地磁珠，不得占用板级 `V3V3_A` |
| NS4150B `VCC` | `V3V3_A` | 不把 `V3V3_A` 写成普通 `V3V3`；禁止直挂 `VMAIN` |
| PY206 FPC `VBAT`/pin 8 | `VLCD` | 面板候选轨与电池 `VBAT` 严格区分 |

音频分轨固定为：`VMAIN → TLV62569 → V3V3`（含 ES8311）→ 磁珠或负载开关 → `V3V3_A`（仅 NS4150B）。`VMAIN` 是这条链路的上游，不是功放或 codec 的器件供电网。

BQ25895 的 `PMID`、`REGN`、`SW`、`BTST` 是器件局部节点，不属于对外电源轨：文档中分别写作 `VPMID`、`VREGN`、`SW_BQ`、`BTST_BQ`，必要时在括号中附原始网表编号。`BAT_NTC`、`SYS_EN`、`LCD_EN` 等是温度或控制信号，不归入电源轨表。

## 4. 测试点和后续文档写法

正式测试点名为：`TP_VBUS`、`TP_VBAT`、`TP_VSYS`、`TP_VMAIN`、`TP_V3V3`、`TP_V3V3_A`、`TP_VLCD`。后续文档按“网络名（用途/边界）”首次展开，例如“`VBUS`（USB-C 5 V 受电输入）”，不要再写 `VBUS_5V`、`BAT_PROTECTED`、`BQ_SYS`、`SYS_MAIN`、`3V3`、`3V3_AUDIO`、`LCD_VBAT`、`M100_VIN`、`TP_3V3` 或其变体作为新网络名。
