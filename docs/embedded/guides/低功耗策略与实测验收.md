# 低功耗策略与实测验收

> 文档状态：EWF（电子木鱼）设备侧低功耗方法学与验收合同，自 `legbot_watch/docs/guides/手环全链路低功耗策略与实测验收.md` 适配。EWF `Embedded/` 仍为绿地（未进入实施），目标板/原理图未冻结，本文全部实测条目在取得实现与真机证据前统一 `DEFERRED`。
> 固件平台：ESP32-S3（N16R8），ESP-IDF ≥5.5.4,<5.6.0，LVGL 8.4。
> 引脚/板级唯一权威：`ARCHITECTURE-SPINE.md` §板级合同（seed；冲突一律以 spine 为准，先改 spine 再调整）。
> 最近更新：2026-09-08

本文定义 EWF 从 PVDF 敲击、触摸、显示、音频、Air780EGP 4G 同步到本地持久化回写的全链路低功耗合同。本文中的时序与阈值是**实施目标**；只有「验收记录」明确标记 `PASS` 且注明适用于最新审查补丁的项目才表示已验证。没有目标板、示波器或功耗仪证据的项目统一标记 `DEFERRED`，**不得从编译成功推导出实际功耗达标**。

本文使用以下状态：

| 状态 | 含义 |
| --- | --- |
| `IMPLEMENTED` | 软件路径已存在，不代表已通过最新回归或真机验收 |
| `IN_PROGRESS` | 代码正在合并或审查，不得按已实现发布 |
| `PASS（最新软件回归）` | 当前工作树已通过对应自动化或构建；不替代真机功耗证据 |
| `PASS（历史基线）` | 已有一次真实测试通过，但发生在当前审查修复之前，必须最终复验 |
| `DEFERRED` | 缺少规格书、原理图或目标板闭环，不得填入推算的 PASS |

> **EWF 现状提示：** 本仓 `Embedded/` 尚无固件，legbot 的历史 `PASS` 只能作为方法学与先例（同型号 CO5300/CST9217/ES8311/NS4150B 面板与共享 I²C 资源基线），**不能**当作 EWF 的验收证据。EWF 的每项功耗结论都必须在自己的目标板上重新闭环。

## 1. EWF 低功耗边界（不可破坏的系统约束）

- **唯一产品联网链路是 Air780EGP 4G（AD-14）。** 固件只在敲击/设置触发的**活动窗口**内发起一次 HTTPS 上报（`local_total`/`acked_total`/`round_id`/`round_cursor` 等，见 spine 同步字段清单），上报后回到离线低功耗记录；不维持长连接、不做周期轮询。ESP32-S3 的 BLE/Wi-Fi 仅作硬件能力保留，**固件不配置为产品通道**；Air780EGP 的 GPS/GNSS 能力默认关闭，不进入产品功耗路径。
- **正式输入只有两类（AD-1/FR-E-002/003）：** `physical_pvdf`（低功耗比较器唤醒 IO11 + ADC 二次确认 IO9）与亮屏木鱼页电子木鱼点击 `device_touch`，二者进入**同一个**有效敲击队列。除该队列外任何路径不得推进正式累计。**熄屏首次触摸只唤醒、不计数**，需亮屏后下一次木鱼页点击才生成 `device_touch`。
- **充电期间暂停实体/触摸输入、经文推进与音频（AD-13）。** 充电中、完成遮罩中与故障锁定中直接忽略输入。
- **低电时先保证累计计数落盘，再执行其他，不主动断网（AD-13）。** 计数以本地高水位持久化（AD-15），断电/重启后恢复本地高水位并可离线续敲。
- **PWR 长按开关机由板级电源电路负责，固件不模拟软件关机（AD-13/FR-E-001/007）。** 运行态 PWR（IO46）只作输入：短按唤醒/进入页面，不输出驱动，不改变关机态 PWR+BOOT0 下载合同。
- **离线积压上限 1000**，达到上限拒绝新输入并提示。
- **USB-Serial-JTAG 是唯一调试通道（AD-11）。** GPIO19/20 为 USB D−/D+；USB 连接时禁用自动 light sleep，防调试串口失联。

## 3. 显示、触摸与 MCU 电源管理

### 3.1 CO5300 AMOLED

目标熄屏顺序：

1. 停止新 LVGL flush，等待当前有界 QSPI 事务完成；
2. 发送 `DISPOFF`；
3. 发送 `SLPIN`；
4. 等待至少 120 ms；
5. 将 IO47（屏幕 EN / 偏压轨）拉低，关闭面板/偏压电源轨。

目标亮屏顺序为：IO47 上电 → 面板复位和初始化 → 退出 sleep → **在 `DISPOFF` 状态**恢复目标亮度 → 提交并确认一整帧 LVGL 像素（整帧 DMA 完成）→ 最后执行 `DISPON`。恢复失败只允许一次有界重试并记录中文诊断，**不得无限复位**。

绿色/黄色闪屏根因（详见 `docs/embedded/troubleshooting/CO5300-熄亮屏闪屏与整帧时序.md`）：冷启动与熄屏恢复都会复位 CO5300 GRAM；若复位后立即以初始化表的 `0xFF` 亮度执行 `DISPON`，而 LVGL 首帧稍后才异步提交，用户会短暂看到未定义像素。因此 init/resume 全程保持 `DISPOFF`，UI 将「允许隐藏 flush」与「物理已点亮」拆成独立事实，只有整屏 DMA 完成后才同步点亮。

软件分阶段状态机应可中途恢复：失败时保留已完成阶段，resume 从真实阶段（`DISPLAY_OFF/PANEL_SLEEP/RAIL_OFF`）继续；后台亮度更新只锁存目标值。CO5300 亮度/熄屏控制寄存器一律来自数据手册（Display On/Off、Sleep In/Out、亮度命令），**禁臆造**。

### 3.2 触摸与唤醒

- CST9217 使用 IO39 中断和数据手册公开的自动监测能力；**不写未被数据手册/驱动证明的 sleep 寄存器**。
- 唤醒源限定为运行态 PWR IO46、触摸 INT IO39（熄屏首触只唤醒）、PVDF 比较器输出 IO11（实体敲击唤醒 + ADC 二次确认）。PWR 持续按住不得形成唤醒风暴。QMI8658C INT1（IO41）为未来 WoM 扩展，MVP 不接入唤醒路径。
- 共享 I²C（IO1/2，挂 CW2015/CST9217/ES8311/QMI8658C）的 `allow_pd` 只能在上述器件 light-sleep 恢复测试通过后启用。

### 3.3 ESP32-S3 电源管理

已配置动态频率 40–240 MHz、tickless idle 与自动 light sleep（实施时确认 sdkconfig）。USB-Serial-JTAG 调试连接通过 `CONFIG_USJ_NO_AUTO_LS_ON_CONNECTION=y` 持有调试锁；该锁只保护有线调试，拔掉 USB 后仍按自动 light sleep 合同运行。

启动阶段先获取 `ESP_PM_NO_LIGHT_SLEEP` 锁，再配置 automatic light sleep，以便在内部堆尚未碎片化时预留 CPU/Cache retention；CO5300、CST9217、音频和 GPIO 唤醒链全部就绪后才释放启动锁。服务启动顺序固定为：输入/计数服务 → 显示 → 音频 → 4G 同步服务（不联网时仅常驻等待活动窗口）。

UI、音频与 4G 同步**只在临界窗口持有 PM lock**；网络活动窗口从唤醒模组到上报完成/回退到低功耗为临界区，窗口外不得保留锁。服务任务使用 queue、notification 和 deadline，**稳定空闲态不得保留 10/20 ms 固定轮询**。

音频空闲时 NS4150B PA_EN（IO48）回到禁用；静音/暂停/故障路径同样回到禁用（spine 板级合同）。低电或熄屏后不主动触发音频。

### 3.4 ESP-IDF API 依据（锚定 ≥5.5.4,<5.6.0）

下表只锁定 ESP-IDF v5.5.x 与 `esp32s3` 目标，不使用 `latest`/`stable` 或其他芯片页面作为实现依据。

| 实现点 | v5.5.x 依据 | EWF 约束 |
| --- | --- | --- |
| 动态频率与自动 light sleep | `esp_pm_configure()`、PM lock（`esp_pm_lock_create/acquire/release`）与 Power Management 文档 | CPU 40–240 MHz；4G 活动窗口/显示转换等关键区持锁，其余只在实际临界窗口持锁 |
| GPIO light-sleep 唤醒 | `gpio_wakeup_enable()` 与 `esp_sleep_enable_gpio_wakeup()` | IO11/IO39/IO46 由各 BSP 先配置有效电平，应用只开放 GPIO 唤醒源；IO46 永远为输入 |
| 隐藏首帧与显式点亮 | `esp_lcd_panel_disp_on_off()` | `esp_lcd_panel_init()` 后先保持 `DISPOFF`，允许 LVGL 写入一帧确定像素；整帧 DMA 完成后才执行 `DISPON` |
| USB 调试不自动休眠 | `CONFIG_USJ_NO_AUTO_LS_ON_CONNECTION=y`（USB-Serial-JTAG Kconfig） | 该锁只保护有线调试；拔线后仍按自动 light sleep 合同运行 |

## 5. 验收记录与功耗实测模板

### 5.1 固定测试条件

每次记录板号、发布 ELF SHA-256、固件 commit、SIM/运营商、RSSI/注册状态、屏幕亮度、日志级别、USB 是否断开、测量仪器与采样率。所有功耗采集必须从电池端或功耗分析仪供电并**断开 USB 数据线**；熄屏稳定 10 分钟后记录至少 30 分钟波形。

单变量 A/B 顺序固定为「熄屏 idle 基线 → 显示 RAIL_OFF → 触摸/音频/唤醒链逐项开关 → 4G 活动窗口」，每一步只更换一个变量，并同时记录 IO47、PA_EN、Air780EGP 电源轨与触摸 INT。任何单次电流读数都不能单独证明根因或功耗达标。

### 5.3 发布门禁

以下任一项不满足均不得把固件标记为低功耗验收通过：

- [ ] 熄屏状态 MCU 实际进入自动 light sleep，有真机计数与功耗仪证据（无 10/20 ms 固定轮询）。
- [ ] 熄屏面板电源轨关闭（IO47 低），1000 次恢复无白屏、花屏或总线死锁。
- [ ] 触摸/实体敲击唤醒链在拔线（无 USB）状态下工作正常；CST9217 未写未公开 sleep 寄存器。
- [ ] Air780EGP 只在活动窗口内激活并回到离线低功耗，无周期联网；GPS/GNSS 默认关闭。
- [ ] 充电暂停输入/音频生效；低电优先落盘后再执行其他。
- [ ] 计数本地高水位断电/重启恢复，离线续敲正常。
- [ ] 编译与单元测试通过只代表软件路径存在，**不替代**真机功耗验收。

## 6. Deferred 风险

- `DEFERRED-DISPLAY-01`：IO47 电流、整条面板/偏压轨所有权与 1000 次恢复循环未在 EWF 目标板执行。
- `DEFERRED-TOUCH-01`：CST9217 监控模式实际电流、共享 I²C `allow_pd` 恢复与拔线后 light-sleep 唤醒未验证。
- `DEFERRED-PM-01`：自动 light sleep 占比、启动 PM 锁释放时机、显示转换 PM 锁未在目标板验证。
- `DEFERRED-4G-01`：Air780EGP 活动窗口唤醒/上报/回退的整机电流与弱网行为未测；GPS/GNSS 默认关闭路径待核验。
- `DEFERRED-CHARGER-01`：充电检测去抖与暂停语义需按 EWF 充电方案与 AD-13 验证。
