# CO5300 熄/亮屏闪屏与整帧时序

> 状态：EWF 绿地阶段方法学排障知识。根因与正确时序提炼自 legbot 真机排障（2026-08-07 已验证首帧时序并修复闪屏）；EWF 需在自有目标板上重新闭环。相关方法论见 `docs/embedded/guides/低功耗策略与实测验收.md` §3.1。
> 引脚唯一权威：`ARCHITECTURE-SPINE.md` §板级合同。
> 最近更新：2026-09-08

## 1. 结论（先读）

**症状：** CO5300 冷启动或熄屏恢复瞬间先闪一帧绿色/黄色（未定义像素），随后才显示正常 UI。

**根因：** 冷启动与熄屏恢复都会**复位 CO5300 GRAM**；复位后 GRAM 内容未定义。旧实现随后立即以初始化表的亮度（`0xFF`）执行 `DISPON`，而 LVGL 首帧要稍后才异步提交，于是用户短暂看到未定义像素 —— 这就是闪屏。

**正确顺序（强制）：** `esp_lcd_panel_init()` / resume 之后**全程保持 `DISPOFF`** → 让 LVGL 在隐藏状态提交一整帧确定像素 → **确认整帧 DMA 完成后再执行 `DISPON`**。UI 必须把「允许隐藏 flush」与「物理已点亮」拆成两个独立事实，只有整屏 DMA 完成后才同步点亮。

**一句话：** 先 `DISPOFF` → 等整帧 DMA 完成 → 再 `DISPON`。复位后 GRAM 未定义即点亮是闪屏唯一根因路径，必须从时序上封死。

## 2. 时序细节

### 2.1 熄屏顺序（关）

1. 停止新 LVGL flush，等待当前有界 QSPI 事务完成；
2. 发送 `DISPOFF`；
3. 发送 `SLPIN`；
4. 等待至少 **120 ms**（面板/偏压进入稳定关断前时序）；
5. 将屏幕 EN（IO47）拉低，关闭面板/偏压电源轨。

### 2.2 亮屏顺序（开）

1. IO47 上电，等待面板/偏压稳定；
2. 复位并初始化 CO5300（`esp_lcd_panel_reset` → `esp_lcd_panel_init`），退出 sleep；
3. **保持 `DISPOFF` 状态**，恢复目标亮度；
4. LVGL 在隐藏状态下提交一整帧，**等待整帧 DMA 完成**（整帧像素已写入 GRAM 并收到传输完成信号）；
5. 最后执行 `DISPON`。

恢复失败只允许**一次有界重试**并记录中文诊断，不得无限复位。

### 2.3 可恢复的分阶段状态机

熄屏/恢复应实现为可中断、可续跑的状态机，阶段至少包括 `DISPLAY_OFF`（已发 DISPOFF）→ `PANEL_SLEEP`（已发 SLPIN）→ `RAIL_OFF`（IO47 已拉低）。任一步失败时保留已完成阶段，resume 从真实阶段继续，而不是从初始化表头重来。后台亮度更新只**锁存目标值**，不打断主时序。

## 3. 控制面事实与寄存器来源（禁臆造）

- CO5300 是 AMOLED QSPI 显示控制器，逻辑分辨率 `410×502`，像素格式 RGB565（初始化片段 `3Ah=55`，`77` 为 RGB888）。当前基线 SPI3_HOST、`CONFIG_LV_COLOR_16_SWAP=y`。
- 控制面命令来自 CO5300 数据手册与厂商初始化片段（例：`FE 00` 页/模式、`C4 80` SPI/QSPI、`3A 55` RGB565、`2A/2B` 列/行窗口、`11` Sleep Out、`29` Display On）。**`DISPOFF`/`SLPIN` 及电源时序约束以 CO5300 数据手册 Display On/Off、Sleep In/Out 与 Sleep In 后电源时序章节为准（legbot 追溯证据 HW-CO5300-01：对应数据手册页码），命令码以数据手册为准，驱动不得臆造或拼凑未公开寄存器。**
- AMOLED 没有传统背光；亮度控制是 OLED 亮度命令（如 `0x51`），不是背光 PWM。**亮度档与熄屏控制寄存器的取值/档位一律来自数据手册**，未核验项在样机/原理图前不得冻结。
- 屏幕 EN（IO47）同时承担面板/偏压使能，偏压器件为 OCP21351（`AVDD/OVDD/OVSS`）；IO47 是否同时控制 OCP21351 的 `EN/SRL` 需按 EWF 原理图确认，固件不得假定未核验的所有权。
- 注意事项（EWF 实施需回填核验）：CO5300 4-wire QSPI RGB 传输的 SCL 频率存在数据手册上限（legbot 记录为数据手册限定 50 MHz、板级驱动日志 80 MHz）。该频率与闪屏根因无直接因果，但量产前必须按 EWF 数据手册核验并复测刷新/唤醒性能。

## 5. 实现要点 checklist

- [ ] init/resume 后、完整首帧提交前，不执行 `DISPON`。
- [ ] 「允许隐藏 flush」与「物理已点亮」是两个独立布尔事实；只有整帧 DMA 完成事件到达后才置「物理已点亮」。
- [ ] 熄屏状态机真实落位到 `DISPLAY_OFF/PANEL_SLEEP/RAIL_OFF`，支持从真实阶段续跑。
- [ ] 亮度/熄屏寄存器取值来自数据手册，不臆造；后台亮度更新只锁存。
- [ ] 屏幕转换（`DISPON`/`DISPOFF` 与 IO47 切换）属于临界区，若与 light sleep 交互按需持 PM lock。
- [ ] USB 调试连接时按 `CONFIG_USJ_NO_AUTO_LS_ON_CONNECTION=y` 语义处理，不因调试改动显示时序。
